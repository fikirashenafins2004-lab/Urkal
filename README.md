# UR KAL — Keep your word

A lightweight web/PWA MVP for the UR KAL accountability app.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload these files to a GitHub repository, then import the repository into Vercel.

## Important
This first version uses localStorage, so data stays in the browser/device. It does NOT yet provide real cloud accounts or multi-device sync.

For production, replace localStorage with a backend/database and add real authentication and payments.
